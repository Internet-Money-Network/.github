**Internet Money (IMN)** is an open-source proof-of-work currency built for payments: a block
every five seconds on a BlockDAG, GPU mining with the Hallmark algorithm, no premine, and a
node small enough for a shop to run its own.

It is in development. A test network is running; there is no main network and the coins on the
test network have no value.
